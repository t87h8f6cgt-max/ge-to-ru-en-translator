How to use

GE to RU/EN translator · Georgian → Russian or English

This extension helps you read Georgian websites when there is no decent translation — or the built-in one is broken. Especially useful for government portals, personal accounts, and PDFs.

Getting started

  1. Click the extension icon in the Chrome toolbar.
  2. Turn on the main switch (it becomes “On”).
  3. Choose the target language: RU or EN.
  4. Press Translate.

The extension icon shows a RU or EN badge — so you can see which language is selected.

Switch the interface language with the RU/EN toggle in the top-right corner of the popup (separate from translation language).

Translate a page

The extension walks the text on the open tab and translates Georgian into the selected language. Pop-ups and many nested blocks on government sites work too.

To restore the original text, press Original in the popup or the ↩ button on the page.

Automatic translation

After you grant site access once, the extension automatically translates Georgian pages while it is on. You do not need to configure each site separately.

To stop automatic translation, turn off the main switch in the extension popup.

Floating button on the page

A floating button appears in the bottom-left corner:

  • GE → RU or GE → EN — translate into the selected language;
  • ↩ — restore original.

Handy when you don’t want to open the popup every time.

Selection only

  1. Select text on the page.
  2. Right-click → Translate selection (GE→RU/EN).

The extension must be on. Only the selection is translated, not the whole page.

PDF

Open a PDF in a Chrome tab and press PDF in the popup. A side panel opens: text is extracted and translated.

Local files (file://) are blocked by Chrome by default. Allow access once:

  1. Open chrome://extensions
  2. Find GE to RU/EN translator
  3. Enable Allow access to file URLs
  4. Open the PDF again and press PDF

Leftover Georgian text

This happens on complex sites: text loads later or sits inside nested frames (iframes).

  • Wait 1–2 seconds and press Translate again.
  • Under More, turn on Highlight leftover ka — untranslated spots light up.
  • Input fields and text you are typing are intentionally left alone.

Report a bad translation

Under More there is Report bad translation. It opens a GitHub issue draft with the page URL and text samples (GitHub account required). The text is also copied to the clipboard so you can send it another way.
